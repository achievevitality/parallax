# Codex extraction lane

Independent extraction pass for comparison with the root-level Claude extraction lane and Brenda's Loom-guided pass. Each finding should cite its source window and message number. Do not merge findings across lanes before comparison.

Status tags for claims: 🟢 corroborated · 🟡 modal/candidate · 🟠 overreach found · 🔴 disconfirmed/withdrawn.

Sensitive personal material belongs in a private, downloadable companion file unless Brenda explicitly approves repository inclusion.

## Source notation

Every entry uses Claude's existing form: `P4, msg 145` for one turn and `P4, msgs 514–521` for a range. Use `Kernel V4 §H` for kernel text. The complete entry template is in [FINDING-FORMAT.md](FINDING-FORMAT.md).
