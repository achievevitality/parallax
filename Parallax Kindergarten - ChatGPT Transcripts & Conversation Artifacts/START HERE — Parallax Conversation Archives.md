## What is preserved

Speakers, original message timestamps in UTC, message IDs, formatting, emojis, and recovered visuals are present in the reading editions. Source graphs preserve returned branches, tool records, metadata, and full content objects. Every PDF passed a full entry-by-entry text comparison and representative rendered-page inspection. Machine files reconstruct the complete captured source object.

Completeness applies to the source returned at capture time, not later live changes or deleted/unreturned data. Recovered writing blocks, images, and available research notebook files are copied as artifacts. Some external attachment/sandbox/library files remain references rather than recovered binary copies; artifact indexes identify that distinction. The archives do not silently substitute file references for file copies.
