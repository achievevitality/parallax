# P2 — Ready to share

**Human reading:** P2-human-readable-FINAL.pdf (1,270 pages). Preserves speakers, source UTC timestamps, message IDs, formatting, emojis, and recovered visuals. It contains the complete saved active conversation without summaries, and embeds the exact original JSON source.

**Other ChatGPT or Codex windows:** Start with P2-conversation.md for reading. For complete archival processing, use P2-machine-readable-FINAL.zip. The ZIP contains the byte-identical original JSON, all graph records and metadata, smaller JSONL chunks, numbered readable parts, recovered artifacts, and verification reports. The original JSON is the preservation master. Markdown is a reading view, not a substitute for every original field.

**Completeness:** Verified against the captured ChatGPT source object. Later live changes and data not returned in that object are outside the archive. The PDF covers the active path; the machine archive also preserves alternate branches and tool records.

**Artifacts:** Recovered writing blocks, conversation images, and embedded visuals are included. Images retain the unmodified bytes served by ChatGPT; some uploads were re-encoded by ChatGPT, so byte identity with the original upload is not claimed. Original binary files behind other attachment, sandbox, or library links are not all recovered. Their references and available metadata remain in the source; artifacts/file-reference-index.json identifies attachment and sandbox references. This is a complete conversation-record archive, not a claim that every externally linked file is copied.

**Verification:** human-readable-verification.json and full-pdf-text-audit.json cover the PDF; P2-machine-verification.json and SHA256SUMS.json within the ZIP cover source reconstruction and package integrity.
